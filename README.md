# 📝 To-Do List Web App (Vanilla JavaScript)

This is a simple and interactive **To-Do List Web Application** built using **HTML, CSS, and Vanilla JavaScript**.  
It allows users to add tasks, mark them as complete, and delete them — all without page reloads.

---

## 🚀 Features

- ➕ Add new tasks dynamically  
- ✔ Mark tasks as completed (toggle)  
- ❌ Delete tasks  
- ⚡ Instant UI updates using DOM manipulation  
- 🎨 Clean and responsive UI  
- 🧪 Works smoothly on Live Server  

---

## 🛠 Technologies Used

| Technology | Purpose |
|-----------|----------|
| **HTML**  | Structure of the web app |
| **CSS**   | Styling and layout |
| **JavaScript (ES6)** | Adding interactivity & DOM manipulation |
